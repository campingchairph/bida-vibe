# sounds/free/

The admin's **Sound manager** in the app writes the sound files here, so you don't need to touch this folder. See [../sounds/README.md](../README.md).

You can still add files by hand (commit and push): the pad name = the file name, and a leading number sets the order (`01-Palakpak.mp3` shows as **Palakpak**, first). Max 8 files.
